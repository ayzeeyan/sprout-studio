# Start Here: How the Academy Works

Welcome! Sprout Academy teaches programming by having you write real code in the real editor. This guide takes three minutes and shows you how everything fits together.

## The learning loop

Every lesson follows the same rhythm:

1. **Read** the short lesson text (and, if you like, the matching Handbook guide).
2. **Write** code in the editor on the right. The starter code gives you a head start.
3. **Run Tests** to check your work privately. Nothing is recorded, so experiment freely.
4. **Submit** when you're happy. A passing submission completes the lesson and earns XP.

> Tip: Run Tests as often as you want. Only Submit counts as an attempt.

## Requirements tell you what "done" means

The **Requirements** card lists exactly what the grader checks, such as "uses a repeat block" or "prints Sprout three times". After you run tests, each requirement turns green or red. A red one explains what was expected and what actually happened.

## Hints when you're stuck

Each exercise has hints that go from a gentle nudge to a near-solution. You can reveal a few hints per day, and hints you've already revealed stay free to reread. Try thinking for a minute before you reach for one — that's where most of the learning happens.

## Streaks, goals, and levels

- **Streak**: practice on consecutive days to grow your streak. Submitting an exercise or reading a guide counts.
- **Daily goal**: earn 30 XP in a day. The ring in the status bar fills up as you go.
- **Levels**: every 100 XP is a new level.

If you prefer to learn without points, turn off **Show levels, XP, and achievements** in **Profile & Progress**.

## Learning while you code

Open any file in the Workspace and look at the **Learn** tab in the Inspector. It lists the programming ideas your code uses and links each one to a lesson. The Academy follows you everywhere in Studio.
